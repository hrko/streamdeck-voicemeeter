# VoiceMeeter for Stream Deck

[English](README.md) | 日本語

Stream DeckからVoiceMeeterのゲイン・ミュート・MacroButtonsを操作するプラグインです。
Stream Deck +のダイヤルでチャンネルを操作し、タッチディスプレイでレベルを確認できます。
キーにはMacroButtonsのボタンを割り当てられます。

## 機能

この節は**0.1.6開発版**の機能を説明しています。ダウンロードできる0.1.5プレリリースとは機能が異なります。開発版のビルド方法は[開発ガイド](docs/development.md)を参照してください。

| アクション | 操作 |
| --- | --- |
| ゲイン操作（Gain Control） | 回転でゲインを調整し、押下でミュートを切り替えます。既定ではタップでミュート切り替え、長押しで0 dBへ戻します。タップ・長押しの動作は設定で変更・無効化できます。 |
| 2チャンネルのゲイン操作（Gain Control Combo） | タップで操作対象を選び、回転でゲイン調整、ノブ押下・長押しでMuteを切り替えます。従来の押し込み回転モードも選択できます。 |
| Macro | Toggleでは押すたびにON/OFFを切り替え、Pushではキーを押している間ONにします。 |
| ゲイン操作ボタン（開発版） | キーでゲインを増減・設定したり、ミュートを切り替えます。静的アイコンまたは2キーでつながる横／縦フェーダーを選べます。 |

- チャンネル名、ゲイン、ステレオレベル、各種状態を表示します。選択候補にはVoiceMeeterのラベルを併記し、種類はStrip（入力）／Bus（出力）で表示します。
- Material Symbolsの書体・太さ・塗りなどを変更できます。MacroキーはON/OFF別のアイコンと背景色を設定できます。
- 音声関連を先頭に並べたアイコンピッカーで、英語名やコードポイントから検索できます。通信は不要です。
- ゲイン操作ボタンでは、チャンネル名・dB値・ステレオメーター・正ゲインの強調色を個別に設定できます。隣接するフェーダーペアの設定は既定で同期します。
- Comboでは左右のチャンネルとゲインの刻み幅を個別に設定できます。
- 設定画面は日本語・英語に対応しています。翻訳リソースを追加して他の言語にも対応できます。
- 設定画面末尾の**プラグイン全体の設定 → 更新レート**で、15（既定）・20・25・30 fpsを選べます。すべてのキー・ダイヤルに適用され、配色プリセットとは別に保存されます。同時表示数が多くコマ落ちする場合は値を下げてください。

タッチ操作、フェーダーペア、共有配色プリセット、トラブル対処の詳細は[利用ガイド](docs/usage.ja.md)を参照してください。

## 必要な環境と提供状況

- Windows 10以降（x64）とStream Deckソフトウェア6.4以降。
- 別途インストールしたVoiceMeeter Basic／Banana／Potato。
- ダイヤル操作にはStream Deck +、Macro・ゲイン操作ボタンにはStream Deckのキーが必要です。
- Macroで使うボタンは、VoiceMeeter MacroButtons側でも設定してください。

バージョン0.1.5を[プレリリースとして公開しています](https://github.com/hrko/streamdeck-voicemeeter/releases/tag/rust-v0.1.5)。安定版ではありません。
主な実機検証環境はWindows 11／Stream Deck +／Potatoです。
Basic／Bananaでは起動・種別判定・チャンネルの選択肢を確認していますが、全機能の検証は完了していません。
Windows 10とStream Deck 6.4は未検証です。詳細は[実機検証記録](docs/hardware-validation.md)を参照してください。

## インストール

1. VoiceMeeterとStream Deckソフトウェアを別途インストールします。VoiceMeeter DLLは同梱していません。
2. [0.1.5のリリースページ](https://github.com/hrko/streamdeck-voicemeeter/releases/tag/rust-v0.1.5)から`.streamDeckPlugin`ファイルをダウンロードします。チェックサム確認用の`.sha256`ファイルも添付しています。ソースからビルドする場合は[開発ガイド](docs/development.md)を参照してください。
3. パッケージをStream Deckで開き、インストールを承認します。
4. Stream Deck上の現在の表示名である**VoiceMeeter (Rust)**からアクションを追加し、設定画面でチャンネルまたはMacroButton IDを選択します。

チャンネル番号とMacroButton IDは0から始まります。
旧プラグインの設定は移行されないため、インストール後に設定し直してください。旧プラグインとは併存できます。

## 使い方とトラブルシューティング

VoiceMeeterが利用可能になると自動的に再接続します。切断中の操作は復旧後に再実行しません。
MacroのPushを保持したままVoiceMeeterを再起動した場合、再起動前の解放操作は新しい接続へ送信しません。
ON状態が残った場合は、改めてキーを押して離してください。

インストールの詳細、チェックサムの確認、ログの取得方法は[利用ガイド](docs/usage.ja.md)を参照してください。
不具合を報告する際は、Windows・Stream Deck・VoiceMeeterのバージョン、使用したアクション、再現手順を添えてください。
