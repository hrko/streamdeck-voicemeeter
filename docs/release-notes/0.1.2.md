# VoiceMeeter (Rust) 0.1.2 development candidate

This candidate remains a draft prerelease pending the remaining acceptance checks.

Changes since 0.1.1:

- Restore the Go touch-display layouts, native labels, state indicators, gain
  bars and centered Macro icons with ON/OFF titles. The React PI is retained.
- Enable title defaults for new actions. Existing actions created by an early
  Rust build may retain hidden titles; enable titles in Stream Deck's title
  controls, or recreate those actions after saving their settings.
- Use normal worker shutdown for development updates so held Push buttons are
  released and VoiceMeeter logout runs before exit. Earlier development helpers
  could forcibly terminate the process and leave connection indicators behind.
- Keep debug development output separate from release packaging, preserving
  the previous installed package when switching to a development link.
- Isolate native smoke tests from the real mixer and verify fresh diagnostic
  logs, normal exit, invalid-launch errors and event-driven shutdown.
- Expand SDK/worker coverage for shared Push ownership, shutdown ordering,
  rapid gain changes, limits and reversal.

Observed on Windows 11 / Stream Deck + / Stream Deck 7.0.3 / Potato 3.1.2.2:
normal Gain/Combo/Macro operation, offline recovery without replay, Push release
on page/target change, shared displays, font controls, Japanese labels, corrected
falling meters and restored Go appearance. After a connection-display incident,
meter/controls recovered; a quiescent restart reduced the full R display and
reconnecting this plugin added one indicator.

Still unverified: repeated-update connection-count stability, remaining manual
edge cases, full target/flag coverage, embedded PI comparison and localization,
Windows 10, Basic/Banana and the declared minimum Stream Deck 6.4. Automated
fake-backend results do not establish those hardware results. See the detailed
hardware acceptance record before publishing or presenting this as stable.
