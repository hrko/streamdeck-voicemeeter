# VoiceMeeter (Rust) 0.1.3 development candidate

This draft supersedes the earlier development candidates. It is not a stable
release; the remaining manual acceptance checks are recorded in
`docs/hardware-validation.md`.

Changes since 0.1.2:

- Macro keys retain their existing image while awaiting the first state sample
  after a page change. This prevents a brief false offline slash; actual outages
  still show the slash. The owner confirmed the visual fix.
- Development installation stops the plugin normally, including any process
  automatically relaunched while the tray host is closing. It no longer issues
  a redundant CLI restart after starting the host.
- Login/logout diagnostics include process IDs and API return codes. In a
  controlled update on the owner's machine, both outgoing processes returned
  logout=0 and the owner confirmed the R count stayed at six before/after.
  Older residual indicators were not removed, and this is not a long soak test.

Includes the earlier Go touch/key appearance restoration, falling peak meters,
native titles, React PI, extensible English/Japanese localization, offline
recovery, independent Combo settings and Macro Push/Toggle behavior.
Native smoke tests never log into the real mixer. SDK/worker regression tests
cover page reentry, real simulated outages, shared Push ownership and shutdown
release ordering.

Hardware observations apply to Windows 11, Stream Deck + with app 7.0.3, and
VoiceMeeter Potato 3.1.2.2. Windows 10, Basic/Banana and Stream Deck 6.4 remain
unverified, as do the remaining manual edge/PI/performance cases in the record.
The plugin has a separate ID and does not migrate old Go settings. Early Rust
actions may retain hidden native titles; enable them in Stream Deck's title
controls or recreate those actions after saving their settings.

The repository's source-available license permits streaming and business use;
paid plugin distribution or paid-product bundling requires permission.
Third-party components retain their own licenses. VoiceMeeter DLLs are not bundled.
