# VoiceMeeter (Rust) 0.1.4 development candidate

This draft includes the 0.1.3 functionality and lifecycle fixes, plus a PI text
font correction to `system-ui`. The owner confirmed that the corrected font
appearance is acceptable alongside the built-in inspector.

Additional owner checks on Windows 11 / Stream Deck + / Potato confirmed rapid
gain rotation and -60/+12 dB limits, overlapping Macro Push ownership, fading
long labels, PI Tab navigation/editing, rejection of invalid step values without
saving them, and missing-codepoint warning/fallback.

This remains a development candidate. Push shutdown/restart edge cases, host
language switching, extended connection-count observation and the remaining
hardware matrix are recorded in `docs/hardware-validation.md`. Windows 10,
VoiceMeeter Basic/Banana and Stream Deck 6.4 are not verified environments.
Older residual Remote API indicators have not been identified or cleared.

The separate plugin ID requires reconfiguration; old Go settings are not
migrated. The source-available license allows streaming and business use;
paid plugin distribution or paid-product bundling requires permission.
Third-party rights and notices are preserved. VoiceMeeter DLLs are not bundled.
