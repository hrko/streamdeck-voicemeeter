# VoiceMeeter for Stream Deck 0.1.5 (prerelease)

Includes all earlier candidate functionality and these owner-confirmed fixes:

- Karaoke lights the virtual-strip center indicator in Mono cyan; MC alone
  retains red.
- PI channel choices follow the connected edition: Basic has 3 strips/2 buses,
  Banana 5/5, Potato 8/8. Existing unavailable targets remain visible as disabled
  selections and are never silently redirected to channel zero.
- Normal Stream Deck exit releases held Macro Push buttons before logout.
  Queued Macro writes are confirmed against raw status with a 500 ms bound.
  The owner confirmed OFF without having to restart Stream Deck.

English/Japanese display, settings retention across language switching, Combo
tap boundaries and the earlier functional/PI checks passed on the owner's
Windows 11 / Stream Deck + (firmware 2.0.3.2) / Potato setup. Basic/Banana startup,
edition detection and corrected PI choices were also checked; this does not
establish full feature coverage on those editions.

Mixer restart intentionally discards old Push ownership. A retained ON state
must be reset manually or by a fresh press/release; old releases are not replayed
into a new mixer session. Extended stability observation was deferred by the
owner to daily use. Windows 10 and Stream Deck 6.4 remain untested. Other
validation limits are recorded in `docs/hardware-validation.md`.

This is a public prerelease with a separate plugin ID and no
automatic migration from Go settings. The source-available license permits
streaming/business use; paid distribution or paid-product bundling requires
permission. Third-party rights/notices are preserved; VoiceMeeter DLLs are not
included.

## Install

Download the attached .streamDeckPlugin file and open it with Stream Deck.
The .sha256 file contains its SHA-256 checksum. Windows x64, Stream Deck 6.4
or later and a separately installed VoiceMeeter are required.
Third-party notices and license texts are included in the plugin archive.
