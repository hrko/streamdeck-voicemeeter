# VoiceMeeter for Stream Deck 0.1.6 development candidate

- Add Gain Button: signed relative gain, absolute gain and mute toggle on keys.
- Add complementary horizontal/vertical fader halves with reference-based rounded
  white rails and ring thumbs. Step sign determines which half is displayed.
- Optional fader colors, positive-gain highlighting, channel labels, dB and stereo
  meters can be enabled independently. Static keys reuse icon/font/color controls.
- Add offline icon search with frequently used audio icons first, English-name
  and code-point search; remove the standalone code-point input.
- Add native background color pickers alongside hexadecimal inputs.

- Synchronize adjacent fader halves by default; clip labels to the filled rail.
- Share editable user color presets across gain keys and dials, including
  transparent variants and component opacity controls.
- Customize single-channel tap/long-press and Combo long-press actions, including
  VoiceMeeter commands. Combo defaults to touch selection with a visible marker.
- Select a global refresh rate of 15 (default), 20, 25 or 30 fps.
- Show VoiceMeeter labels in channel choices and identify Strip/Bus as input/output.
- Add a [Japanese user guide](../usage.ja.md) and update the [English guide](../usage.md).

Existing settings receive defaults for the new fields. VoiceMeeter is installed
separately; no DLL is redistributed. Windows 10 and minimum Stream Deck 6.4
remain untested; earlier coverage is recorded in `docs/hardware-validation.md`.
Hardware checks have covered gain-key controls, paired display and other development changes; see the validation record for the exact tested scope. Newly added settings are not all hardware-verified.
This version is not yet publicly released.
